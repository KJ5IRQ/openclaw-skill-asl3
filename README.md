# ~~OpenClaw Skill: AllStar Link Control (ASL3)~~

> ⚠️ **This repository is archived and no longer maintained.**
>
> The backend API from this project has been extracted, rewritten from scratch, and
> released as a standalone community tool:
>
> ## 👉 [ASL3-API](https://github.com/KJ5IRQ/asl3-api)
>
> **ASL3-API** is a clean, production-grade REST API for AllStar Link node control with:
> - No OpenClaw, Moltbot, Telegram, or PowerShell dependencies
> - 16 endpoints covering status, node lookup, connect/disconnect, DTMF, macros, COP commands, and live keyed state
> - In-memory cache of 40,000+ AllStar nodes (instant lookups)
> - Rate limiting, startup config validation, structured data formats
> - Dual-mode installer (guided and auto)
> - Full documentation
>
> If you came here looking for a way to control your AllStar node over HTTP,
> **[ASL3-API](https://github.com/KJ5IRQ/asl3-api) is what you want.**
